Start the app by running:

  - 2 cmd terminals
  - `cd smartfm` (on both)
  - `npm install` (once on either terminal)
  - `npm run server` on one
  - `npm run dev` on the other
  - click on the link in the `npm run dev` terminal

Run app test cases:
  - Open 1 cmd terminal
  - `cd smartfm`
  - `npm run test`
Happy ordering!
